# CyberattackDetectionML
CRISP-DM data science project analysing 6,000 network sessions for a financial organisation: classifying sessions as BruteForce or Benign (Decision Tree vs KNN) and predicting average packet size (Linear Regression vs Decision Tree Regressor) with pandas and scikit-learn. Built for Fundamentals of AI &amp; Data Science (COMP H2706), TU Dublin.
